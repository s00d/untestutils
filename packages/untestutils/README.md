# untestutils

Live prepare → start → URL tests for Vitest and Playwright. Shared prepare stays fast enough for CI.

**Docs:** [Why](https://s00d.github.io/untestutils/why) · [Get started](https://s00d.github.io/untestutils/guide/getting-started) · [Site](https://s00d.github.io/untestutils/)

```bash
pnpm add -D untestutils vitest
pnpm dlx untestutils init --preset vitest
```

Config imports `untestutils/vitest/plugin`; specs import `untestutils/vitest`.
