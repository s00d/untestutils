## CLI templates

Generated by `untestutils init`:

- preset `vitest` — plugin config + `staticDir` smoke
- preset `playwright` — `createPlaywrightConfig` + harness spec
- preset `nuxt` — `nuxt({ run })` + fetch smoke
- preset `full` — combination

Source templates live under `packages/cli/src/templates/`.

## Patterns

### Shared host across two Vitest files

Prewarm `site`, call `useHarness('site')` in each file — second file should hit a warm prepare.

### Vitest + Playwright same recipe

Same `recipes.ts` imported into both Vitest and Playwright configs.

### Staging-only Playwright project

`host({ id: 'staging', url: process.env.UNTESTUTILS_REMOTE_URL! })` and skip the project when the env is unset.
