## v0.6.0

### 🚀 Features

- **Honest consumer path (0.6):** CLI dogfood in CI (`test:cli-dogfood`), typed override smoke in playground, Node 20 smoke job
- CLI `init`: `--pm`, documented `--no-install`; nuxt preset ships minimal `fixtures/nuxt`
- CLI `doctor`: Vitest major 4|5, Playwright when config present, optional `@untestutils/perf` / `ai` hints; **`doctor --recipes`** lists ids
- SvelteKit `kitConfig` (JSON-serializable merge onto `svelte.config.*`) with playground dogfood
- Facade: `@untestutils/nuxt` + `vitest-environment-untestutils` are **optional peers** (install for Nuxt)
- Harness DX: unknown / prewarm errors list known recipe ids; Playwright default `testMatch: **/*.spec.ts`
- Optional perf dogfood via `workflow_dispatch` (`run_perf` + `scripts/perf-dogfood.config.ts`)

### 📖 Documentation

- Roadmap / support matrix on **0.6.x**; getting-started Nuxt peer install; matrix vs explicit ids; override JSON-serializable tip

### ⚠️ Migration

```bash
# Nuxt users (no longer pulled by facade):
pnpm add -D @untestutils/nuxt vitest-environment-untestutils
```

## v0.5.3

[compare changes](https://github.com/s00d/untestutils/compare/v0.5.2...v0.5.3)

### 🚀 Features

- Ideal harness (toward 1.0): support matrix + roadmap aligned to **0.5.x**; Nuxt unit in CI (`test:playground:unit`)
- Hard-fail mixing e2e `untestutils()` plugin with `environment: 'untestutils'`
- Typed `nuxt({ nuxtConfig })` via `NuxtConfigOverride`; `defineDriver` normalizes `id`/`share`
- Session IPC: Vitest `provide`/`inject`, shared `session` artifacts, `leaseTarget` / `withHarness` / `prepareOnce`
- Worker-scoped Playwright browser fixture; multi-browser via `injectTestProjects`
- Slim facade: `@untestutils/ai` and `@untestutils/perf` are **optional peers** (install when needed)
- Root `typecheck` covers `@untestutils/nuxt` and framework adapters
- `mockNuxtImport` / `unmockNuxtImport` can share one spec: runtime registry instead of file-level `vi.unmock`
- Remix + SolidStart real fixtures dogfood’d in playground e2e (`frameworks.spec.ts`)
- `resolveBin` filesystem fallback for packages with tight `exports` (vinxi / SolidStart)
- Framework parity: core `matrixRecipe` + `workspaceDeps`; `matrix` / `defineDriver` on vite/next/astro/sveltekit/remix/solidstart
- Typed config overrides on framework adapters (`viteConfig` / `nextConfig` / `astroConfig` / `appConfig`) analogous to Nuxt `nuxtConfig`

### 📖 Documentation

- Explore docs: alternate browsers framed as **perf** spike (Chromiumoxide = Rust CDP throughput, not “Playwright already has CDP”)
- Support matrix / browser-mode guides

**1.0 promise:** ship when the [support matrix](https://s00d.github.io/untestutils/guide/support-matrix) matches CI with no silent gaps; changelog labels stable vs optional.
