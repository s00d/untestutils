## v0.7.0

[compare changes](https://github.com/s00d/untestutils/compare/v0.6.11...v0.7.0)

### 🚀 Enhancements

- **core:** `ManagedProcess` handles from `spawnManaged` (`stop` / `alive` / `logs`); teardown via `stopAllTargets` — undocumented low-level exports `killPidTree` / `killProcessTree` / `isPidAlive` / `reclaimStaleTargets` removed from the package surface
- **core:** Programmatic Vite / Astro / `staticDir` servers run in child-process hosts with real OS `pid` so Vitest-fork `stopAllTargets` can drain `targets.json` orphans; `share: always|never` fails closed without a reclaimable child pid (remote `host` attach exempt)
- **e2e:** Full playground mode matrix (incl. `dev`) for Vite/Next/Astro/SvelteKit/Remix/SolidStart/Nuxt + `assert-e2e-mode-matrix` / live orphan teardown
- **vitest:** Multi-framework unit-env router (`environmentOptions.untestutils.framework`) + shared `@untestutils/vitest/unit-dom`; framework-agnostic unit lifecycle hooks (`registerSetupEntry`, dispose/reset/host helpers)
- **adapters:** Unit-env for Vite/Next/Astro/SvelteKit/Remix/SolidStart (config/runtime/environment + playground boot asserts); Nuxt `resetSharedApp` / `restartSharedApp` aliases
- **nuxt:** Opt-in worker-scoped Nuxt unit app reuse (`appIsolation: 'worker'`) with `resetSharedNuxtApp`, endpoint/mock hygiene, browser-entry (#1821 shape), file-mode remount, host/timers/stubs defaults, `restartSharedNuxtApp` + hot invalidate, isolate-setup + lifecycle fixtures ([#1](https://github.com/s00d/untestutils/issues/1), [#1750](https://github.com/nuxt/test-utils/issues/1750), [#1821](https://github.com/nuxt/test-utils/pull/1821))

### 🩹 Fixes

- **nuxt:** Harden failed-boot / reset dispose (`disposeSharedNuxtApp`, resilient `cleanupAll`, restart after broken custom reset) so shared workers cannot stay half-alive
- **core:** `stopAllTargets(artifactsRoot?, stopOpts?)` forwards `keepEventLoop` through liveStops and registry orphans; scrub ambient `UNTESTUTILS_*_CONFIG_FILE` before child-host spawn

### 📖 Documentation

- Support matrix rewritten as e2e run × unit env × teardown truth tables (Stable only with CI)
- Extending / Core API: process handles + `pid` on local shared servers (`spawnManaged`)

### ⚠️ Notes

- SolidStart `run: 'server'` remains **Experimental** (preview/dev Stable)
- Vitest Browser Mode real CI job remains **Experimental**
- Custom drivers under `share: always|never` should return a reclaimable child `pid` (built-in drivers already do); remote attach omits `stop`/`pid`

## v0.5.3

[compare changes](https://github.com/s00d/untestutils/compare/v0.5.2...v0.5.3)

### 🚀 Features

- Ideal harness (toward 1.0): support matrix + roadmap aligned to **0.5.x**; Nuxt unit in CI (`test:playground:unit`)
- Hard-fail mixing e2e `untestutils()` plugin with `environment: 'untestutils'`

- Worker-scoped Playwright browser fixture; multi-browser via `injectTestProjects`
- Slim facade: `@untestutils/ai` and `@untestutils/perf` are **optional peers** (install when needed)
- Root `typecheck` covers `@untestutils/nuxt` and framework adapters
- `mockNuxtImport` / `unmockNuxtImport` can share one spec: runtime registry instead of file-level `vi.unmock`
- Remix + SolidStart real fixtures dogfood’d in playground e2e (`frameworks.spec.ts`)
- `resolveBin` filesystem fallback for packages with tight `exports` (vinxi / SolidStart)
- Framework parity: core `matrixRecipe` + `workspaceDeps`; `matrix` / `defineDriver` on vite/next/astro/sveltekit/remix/solidstart
- Typed config overrides on framework adapters (`viteConfig` / `nextConfig` / `astroConfig` / `appConfig`) analogous to Nuxt `nuxtConfig`

### 📖 Documentation

- Explore docs: alternate browsers framed as **perf** spike (Chromiumoxide = Rust CDP throughput, not “Playwright already has CDP”)
- Support matrix / browser-mode guides
